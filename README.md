# GTDoom

![License](https://img.shields.io/badge/license-BSD--2--clause%20Plus%20Patent-blue.svg)

An implementation of a Doom engine using the [gTether Engine](https://github.com/gtether/gtether).
This project is used as a testbench for ensuring gTether can be used as a proper engine, and as such
providing full compatibility with all Doom and related formats (Heretic, Hexen, etc) is not the
primary concern. That being said, compatibility will be added on a "best-effort" basis.

Additionally, this engine is written "from-scratch" and is not a
[source port](https://doomwiki.org/wiki/Source_port) in the classical sense as it is not based off
the original Doom source. As such, some things may feel quite different (for example, some of the
physics), although effort will be made to match the original feel as much as possible.
